# Komentář k zákonu č. 191/2016 Sb., o ochraně státních hranic České republiky a o změně souvisejících zákonů (zákon o ochraně státních hranic)

Otevřený komentář k zákonu o ochraně státních hranic — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; hraniční přechod na mezinárodním letišti, povinnosti velitele letadla a provozovatele letiště, ochrana vnějších hranic, dočasné znovuzavedení ochrany vnitřních hranic, náhrada újmy a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2016-00191_2025-10-01`.
